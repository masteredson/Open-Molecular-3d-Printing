# Guia de Contribuição 🚀

Obrigado por se interessar em contribuir para o nosso projeto! Este documento vai ajudar você a configurar seu ambiente de desenvolvimento e entender nosso processo de contribuição.

---

## 💖 Apoio Financeiro (Open Collective)

Se você não é desenvolvedor ou quer apoiar o projeto de outra forma, considere fazer uma doação financeira. Isso nos ajuda a manter o projeto ativo e a pagar pelos custos de infraestrutura.

* **Doe via Open Collective:** [Clique aqui para contribuir]([https://opencollective.com](https://opencollective.com/open-molecular-3d-printing)
* **Transparência:** Todos os fundos e gastos são públicos e visíveis na plataforma.
* **Benefícios:** Apoiadores ganham destaque em nosso README principal.

## 🛠️ Configuração do Ambiente

Siga os passos abaixo para rodar o projeto localmente:

1. **Faça o Fork:** Clique no botão "Fork" no topo superior direito desta página.
2. **Clone o Repositório:** Execute o comando no seu terminal:
   ```bash
   git clone https://github.com
   ```
3. **Instale as Dependências:** Entre na pasta e instale os pacotes necessários:
   ```bash
   npm install
   ```
   *(Substitua pelo comando correspondente se usar Python, Go, Ruby, etc.)*

---

## 📋 Fluxo de Trabalho (Workflow)

Para manter o histórico do Git limpo, siga estas etapas para enviar suas alterações:

* **Crie uma Branch:** Use um nome descritivo para a sua tarefa.
  ```bash
  git checkout -b feature/minha-nova-funcionalidade
  ```
* **Faça Commits Claros:** Siga o padrão de Commits Semânticos (ex: `feat: adiciona botão de login`).
* **Mantenha Atualizado:** Atualize sua branch com a branch principal antes de enviar.
* **Envie o Pull Request:** Abra o PR detalhando o que foi feito e qual issue ele resolve.
